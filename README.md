# Mi Ciclo 4.5.3 — Inicio y fin rápidos

- **Iniciar período hoy**: confirma la acción y registra la fecha actual, sin abrir el selector de fecha.
- **Finalizar período hoy**: confirma el término con fecha actual, guarda el registro cifrado y bloquea la sesión.
- Los controles desplegables permiten elegir otra fecha y ajustar el flujo predominante.
- No cambia el formato cifrado, la clave de almacenamiento ni el historial.
- La sesión puede cerrarse al reiniciar la PWA por decisión del sistema operativo.

Antes de publicar, exporta un respaldo cifrado en cada dispositivo. Sube todos los archivos a la raíz de tu repositorio de GitHub Pages y no elimines los anteriores. Después, comprueba la versión y el historial.
